"!DOCTYPE HTML"

indica al navegador que el documento es de tipo HTML5.

"body & head"

Añadiendo estas etiquetas a tu editor de texto habrás creado la estructura HTML más elemental de una página web

Texto

Para añadir contenido visual al body, tenemos etiquetas como h1 (título principal), h2 (subtítulo) o p (párrafo). De esta manera podemos definir la estructura básica HTML de cualquier página

mover el texto de una esquina a otra

Para poder mover un texto de un lado a otro, tenemos la etiqueta "Marquee".

Colocar una imagen

Esta estructura es de mucha utilidad para cuando quieres darle mas "diseño", tenemos la más simple que es "img src"
